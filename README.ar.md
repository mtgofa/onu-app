**تحكّم في راوتر الفايبر بتاعك من موبايلك.** غيّر اسم الواي فاي وكلمة السر لكل نطاق، اعمل
شبكة ضيوف بعزل الأجهزة، وشوف كل جهاز متصل لايف — من غير ما تفتح صفحة الراوتر وتستنى ريبوت.

مبني لراوتر **Huawei HG8145V5** بتاع **TE Data** (مصر) وأي راوتر هيولتر فايبر تاني بيشتغل
بنفس واجهة HiSilicon (**HG8245H**، **HG8245H5**، **HG8245V5** …).
تطبيق أندرويد أصلي مكتوب بـ Kotlin، من غير روت، من غير إعلانات، من غير تسجيل حساب، وبيشتغل
أوفلاين بالكامل.

---

## بيعمل إيه

| | |
|---|---|
| **اسم الواي فاي وكلمة السر** | غيّر اسم الشبكة وكلمة السر لكل نطاق (2.4G / 5G). بيتطبّق عن طريق `set.cgi` بتاعة الراوتر نفسه، فبياخد **ثواني — من غير ريبوت**. |
| **شبكة الضيوف** | الراوتر مفيهوش زرار ضيوف، فالتطبيق بيعملها: SSID إضافي **بعزل الأجهزة** (الضيوف يوصلوا إنترنت بس مش لأجهزتك). اختار 2.4G أو 5G أو الاتنين. |
| **الأجهزة المتصلة** | قائمة لايف لكل جهاز على الشبكة، مع سرعة الاتصال وقوة الإشارة (RSSI) ومدة الاتصال. |
| **أسماء وأيقونات الأجهزة** | سمّي أجهزتك باسمك (بتتحفظ على موبايلك ومش بتتبعت للراوتر) وأيقونة موبايل/كمبيوتر لكل جهاز. |
| **إعدادات MTU** | اقرأ قيمة MTU الحالية، اعمل اختبار للقيمة الحقيقية، وحطّ القيمة الموصى بيها. |
| **السرعة و DNS** | فحص سرعة التصفح، سرعة لكل جهاز، حجب مواقع بعينها عن طريق DNS، ومعلومات الراوتر (الموديل، IP، مدة التشغيل، حالة الليب والـ WAN). |
| **إنجليزي وعربي** | واجهة عربية كاملة من اليمين للشمال، بتتبدّل من جوه التطبيق. |

كل حاجة شغالة **محلياً على شبكتك**. التطبيق بيكلّم `192.168.100.1` (أو عنوان الـ gateway) وخلاص.

## التحميل

1. افتح صفحة [**Releases**](https://github.com/mtgofa/onu-app/releases/latest) وحمّل ملف
   `ONU-Manager-HG8145V5.apk`.
2. اسمح لفايل مانجر إنه **يطبّح تطبيقات من مصادر مجهولة** لما أندرويد يطلب.
3. افتح الـ APK وطبّقه. التطبيق كمان بيقدر يحدّث نفسه من شاشة «حول».

أو عن طريق ADB:

```bash
adb install -r ONU-Manager-HG8145V5.apk
```

**المتطلبات:** أندرويد 7.0 (API 24) أو أحدث، وموبايلك **متوصّل بواي فاي الراوتر** (التطبيق
بيوصل للراوتر عن الشبكة المحلية — مش بيشتغل على بيانات الموبايل).

## الراوترات المدعومة

التطبيق بيتكلم واجهة HiSilicon الأصلية (`login.cgi`، `set.cgi`، `GetLanUserDevInfo.asp`،
`WlanBasic.asp`، `cfgfile.asp` …) و**بيقرا موديل الراوتر أوتوماتيك**.

| الحالة | الموديلات |
|---|---|
| ✅ **مجرَّب** | **HG8145V5** (TE Data مصر) |
| 🟡 **نفس الواجهة، مش متجرَّب عندنا** | HG8245H · HG8245H5 · HG8245V5 · HG8245H5-V5R019C10 و Boards V5R تانية باسم شركة الشبكة |
| ❌ غير مدعوم | راوترات بواجهة مختلفة (TP-Link، ZTE، Nokia …) |

الموديل بيتقرا من الراوتر نفسه (`var ProductName = '…'`) وبيظهر جوه التطبيق، فما تحتاجش
تخمّن. لو الراوتر بتاعك اشتغل — أو ما اشتغلش — من فضلك
[افتح issue](https://github.com/mtgofa/onu-app/issues) بالموديل، ده بيساعد غيرك.

## أول تسجيل دخول

التطبيق بيكتشف الـ gateway لوحده، وبعدين يسجّل دخول بحساب **`admin`** بتاع الراوتر:

```
GetRandCount.asp  →  login.cgi  →  جلسة (sid)
```

الجلسة قصيرة، فالتطبيق بيعمل دخول تاني أوتوماتيك لما الراوتر يرجّع `403`. شهادة الراوتر
الموقّعة ذاتياً بتتقبل لعنوان الشبكة المحلية بس.

**مهم:** التطبيق محتاج باسورد حساب **`admin`** بتاع الراوتر (نفس اللي بتستخدمه في صفحة الراوتر).
بيتحفظ مشفّر بـ Android Keystore ومش بيخرج من الموبايل خالص.

## الخصوصية والأذونات

- 🔒 **من غير تحليلات ولا تتبع ولا إعلانات ولا سيرفر بتاعنا.** الطلبات بتروح للراوتر بس.
- 🔒 بيانات الدخول محفوظة في خزنة AES-GCM مسنودة بـ Android Keystore، مش نص صريح.
- شهادة الراوتر موثوقش بها من النظام؛ إعدادات أمان الشبكة بتسمح للعنوان المحلي بس.

| الإذن | السبب |
|---|---|
| `INTERNET` / `ACCESS_NETWORK_STATE` | الكلام مع الراوتر على شبكتك المحلية |
| `ACCESS_WIFI_STATE` | عرض اسم الشبكة اللي متصل بيها |
| `REQUEST_INSTALL_PACKAGES` | تحديث التطبيق من جوهه (لما تضغط «تحديث» بس) |

## البناء من المصدر

```bash
# JDK 17، أندرويد SDK فيه platform 34، Gradle 8.9
cd WaslaApp
./gradlew assembleDebug        # app/build/outputs/apk/debug/app-debug.apk
./gradlew assembleRelease      # موقّع بالمفاتيح الموجودة في keystore.properties
```

`minSdk 24`، `targetSdk 34`، Kotlin + Jetpack Compose (BOM 2024.09.02) + OkHttp.
نسخة الـ release بتتوقّع بمفتاح من `keystore.properties` (مش داخل في Git).

```
app/src/main/java/com/hg8145v5/manager/
  MainActivity.kt        الثيم، نقطة الدخول، حوار التحديث
  net/Discover.kt        اكتشاف الـ gateway والموديل
  net/RouterApi.kt       OkHttp، الدخول، set.cgi، تنزيل/رفع الإعدادات، المُحلِّلات
  net/UpdateCheck.kt     قراءة صفحات الإصدارات من GitHub
  data/CredStore.kt      خزنة مشفّرة بـ Android Keystore
  vm/RouterViewModel.kt  الحالة وكل الإجراءات (تعديل لحظي، وتعديلات بريبوت)
  ui/Screens.kt          شاشات Compose (دخول، رئيسية، أجهزة، إعدادات، المزيد)
  ui/Strings.kt          نصوص إنجليزي / عربي
  ui/Theme.kt            الألوان، الخطوط، دعم RTL
```

## إزاي التطبيق بيكلّم الراوتر

- **الإجراءات اللحظية** (الاسم، كلمة السر، الإخفاء، SSID الضيوف، الـ LED) بتروح عن طريق
  `set.cgi` / `setajax.cgi` مع `onttoken` جديد، فبتتطبّق فوراً.
- **التغييرات البنيوية** (حجب DNS، MTU، حدود المستخدمين) بتروح عن طريق ملف الإعدادات:
  تنزيل بـ `cfgfiledown.cgi`، تعديل الـ XML، رفع بـ `cfgfileupload.cgi`، وبعدين ريبوت.
  التطبيق بيوضحلك كل إعداد محتاج إيه.
